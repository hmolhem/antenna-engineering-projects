# Native Model Access

The native CST project is intentionally excluded from ordinary Git history.

The public package provides:

- geometry and material definitions;
- frequency range and observation frequency;
- port locations, directions, and mode count;
- analytical verification;
- selected CST figures;
- explicit numerical limitations.

A native model should only be distributed separately after checking file size, software-version compatibility, embedded paths, personal metadata, and any licensing or course-distribution restrictions.
