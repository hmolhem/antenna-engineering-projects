# Native Model Access

The supplied archive includes the academic LaTeX source, compiled academic PDF, Python verification script, and exported CST figures. It does not include a native CST binary model.

Accordingly, this public portfolio package supports review of the documented geometry and displayed results, but it does not provide full solver-level reproducibility. A future release should add a sanitized native model or a complete model-construction record together with raw S-parameter and far-field exports.
