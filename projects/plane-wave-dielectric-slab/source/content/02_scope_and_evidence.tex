\subsection{Evidence Classes}

\textbf{Analytical evidence} consists of the transmission-line equations, the
half-wavelength matching derivation, regenerated reflection curves, and executable
Python verification.

\textbf{Simulated evidence} consists of the preserved CST screenshots. The parameter
sweep, $|S_{11}|$, $S_{11}$ phase, model geometry, boundaries, port definitions, and
field plots are directly visible. Selected numerical null values are preserved in the
source report and result-table screenshot.

\textbf{Measured evidence} is absent. The project contains no fabricated specimen,
material measurement, field-probe scan, or calibrated microwave measurement.

\subsection{Public Claim Boundary}

The report claims that the observed locations of the simulated reflection minima agree
with the analytical matching condition. It does not claim an exact infinite-plane-wave
solution, convergence-qualified null depth, material-tolerance robustness, or measured
performance. The fundamental-mode result is interpreted despite a reported port-mode
accuracy warning because its trend follows the analytical prediction; this agreement
does not replace a formal port- and mesh-convergence study.
