# Numerical Reliability

The preserved evidence supports the expected monotonic tuning trend and canonical
dipole radiation pattern. The final resonance and S11 minimum are taken from an exact
CST marker. Preliminary tuning values are approximate readings from screenshots.

The supplied project archive did not include the native CST model, raw S-parameter or
far-field exports, solver version/type, mesh statistics, convergence history, or formal
mesh/boundary sensitivity checks. These omissions limit numerical reproducibility and
prevent an uncertainty statement.

The reported -47.01186 dB S11 is referenced to a 73-ohm discrete port. It is not a
50-ohm system qualification and does not by itself establish bandwidth.
